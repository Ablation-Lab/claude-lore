# Official sources

Use these Anthropic sources, and cite the page you used. Each one is newest first where it's a list of changes.

## Claude Code (the CLI, IDE extensions, desktop and web)

- Docs index: `https://code.claude.com/docs/llms.txt` lists every page with a one-line summary. Pick the page, then fetch its `.md` URL (for example `https://code.claude.com/docs/en/hooks.md`). Cite it without `.md`.
- Some pages are very long (hooks, settings, permissions). Ask WebFetch for the exact section you need, and use its `offset` to read on if the answer is cut off.
- Changelog: fetch `https://code.claude.com/docs/en/changelog.md`. It's long, but newest first, so the start is what you need. Entries are by version, without dates. Cite it as `https://code.claude.com/docs/en/changelog` (or the GitHub copy, `https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md`).

## Claude apps (claude.ai on web, desktop and mobile, Claude in Chrome and other apps), plans and billing

- Help Center: `https://support.claude.com`. Search with WebSearch limited to `support.claude.com`, then fetch the article. The full article index is at `https://support.claude.com/llms.txt`, but it's large, so search first.
- Release notes for the apps: `https://support.claude.com/en/articles/12138966-release-notes`.
- Plans and prices: `https://claude.com/pricing`. Prices and limits change often and can differ by country, so always cite the page and its date.

## Claude API, models and the Claude Platform

- Docs index: `https://platform.claude.com/llms.txt`.
- Release notes: `https://platform.claude.com/docs/en/release-notes/overview` (`.md` version available).
- Model overview: find "models overview" in the index.

## Announcements

- `https://www.anthropic.com/news` and `https://claude.com/blog` for launches. Prefer the docs or Help Center for how something works.

## Not official

Third-party blogs, forums, Reddit and videos are not official sources. Don't cite them as confirmation. If they're the only source, say the claim is unconfirmed.
